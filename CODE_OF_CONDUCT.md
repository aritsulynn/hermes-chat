# Code of Conduct

## The short version

Be decent. Assume the other person is trying to help.

- Critique the code, not the person. "This breaks when the session id spaces
  differ" beats "you clearly didn't test this".
- Assume good faith in questions and in review comments. Everyone here is
  working in a second language against a gateway they run themselves.
- Accept that maintainers may hold a change back — especially when it needs a
  manual pass against a real gateway that CI cannot perform.

## Unacceptable

Harassment of any kind, personal attacks, sustained disruption, publishing
someone's private information, and unwelcome sexual attention. Also: arguing about
the gateway's internals as if this repository controls them. It does not.

## Scope

Applies in issues, pull requests, discussions, and any other space this project
happens to run.

## Reporting

Report a problem to the maintainers by opening a private report through GitHub
(_Security → Report a vulnerability_ works, and does not require the issue to be
public). You will not be asked to confront the other person. Reports are handled
as confidentially as the channel allows, and a good-faith report never results in
retaliation.
